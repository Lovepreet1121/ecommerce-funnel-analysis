# 🛒 E-commerce Funnel Optimization & Conversion Analysis

## 📊 Overview

This project analyzes **200K+ user interactions** from an e-commerce platform to understand user behavior, identify conversion bottlenecks, and optimize the purchase funnel.

---

## 🎯 Objectives

* Analyze user journey from **View → Cart → Purchase**
* Identify major drop-off points in the funnel
* Measure conversion rates at user and event level
* Provide actionable business insights to improve conversions

---

## ⚙️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib)
* **SQL**
* **Power BI**

---

## 📁 Dataset

* Time Period: **October – November 2019**
* Total Records: **200,000+ events**
* Features include:

  * event_time, event_type
  * product_id, category_code
  * brand, price
  * user_id, user_session

> ⚠️ Note: Large raw datasets are excluded due to size constraints. A processed dataset is used.

---

## 📈 Key Metrics

* **Total Users:** 40.82K
* **User Conversion Rate:** 6.08%
* **Event Conversion Rate:** 1.58%
* **No Purchase Rate:** 93.92%

---

## 🔍 Key Insights

* Only **~6% users complete a purchase** → severe funnel leakage
* **~94% users drop before purchase stage**
* Largest drop occurs between **View → Cart stage**
* High traffic but low purchase intent suggests **UX, pricing, or trust issues**
* Opportunity to improve **product pages and checkout flow**
